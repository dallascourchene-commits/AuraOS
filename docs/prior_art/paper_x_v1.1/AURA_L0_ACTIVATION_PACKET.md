## Prime law

DO NOT FEED THE AGENT THE WORLD.  
COMPILE THE SMALLEST SOURCE-RESOLVABLE RELATIONAL WORLD SUFFICIENT FOR THE OBJECTIVE.

## State coordinate

`STATE = domain × selected_object × resolution × temporal_generation × epistemic_state × authority × objective`

## Compile

`persistent world -> objective -> universal primitives -> domain frame -> signed relations -> guards -> active subcircuit -> minimum resolution -> exact source if earned -> verified/authorized transition -> provenance`

## Universal distinctions

- persistent != ephemeral
- projection != owner
- relation != permission
- similarity != evidence
- route != authority
- receipt != truth
- grounding != authorization
- repeated evidence != independent evidence
- history may survive after currentness dies

## Signed relational primitives

Encode both what connects and what must remain separate: `DEPENDS_ON`, `DERIVED_FROM`, `SIMILAR_TO`, plus `INDEPENDENT_OF`, `MUST_NOT_AFFECT`, `NOT_AUTHORIZED_BY`, `STALE_RELATIVE_TO`, `CONTRADICTED_BY`, `IRRELEVANT_FOR_OBJECTIVE`.

## Recursive resolution

For any selected object X, use L0-L4 (or generalized N levels): address -> compact invariant -> relations/rationale -> rich linked synthesis -> exact/source-resolvable evidence. Deeper = sharper about a smaller selected world, not necessarily broader context.

## Movement

- UP/DOWN: resolution
- BACK/FORWARD: temporal/genealogical state
- LEFT/RIGHT: typed lateral relation
- DIAGONAL: multi-coordinate transition
- TELEPORT: typed non-local relation/source route
- ENTER/EXIT: domain-frame transition

## Transition order

GUARD -> WEIGHT -> AUTHORITY -> SOURCE/EVIDENCE -> VERIFY -> PROVENANCE.

## Metacognitive coordinate

A worker may explicitly track: where it is, what it is doing, what state it inherited, which evidence changed its model, what remains cold, what authority it lacks, what would falsify its current model, and which source would settle uncertainty. This is functional situated/metacognitive reasoning, not a claim of phenomenal consciousness.

## Correction metabolism

`SOURCE CHANGE -> DERIVED STATE STALE -> TARGETED RECOMPUTE -> NEW GENERATION`

STALE FIRST, THEN RECOMPUTE. Preserve historical source/receipts.

## Stop rule

Do not hydrate because something is interesting. Hydrate deeper when contradiction, currentness, authority, consequence, failed prediction, or explicit exact-source need earns it.

## Acceptance

A receiving worker should predict lawful next transitions, keep prohibited branches cold, distinguish projection from source, correct a false inherited state against current evidence, and resume a task from compact residue without needing the full transcript.


## Version 1.1 transfer / attention extension

A strong worker does not merely retrieve relevant text. It maintains a bounded **active decision surface** and an explicit recoverable cold set.

Observable salience heuristic (not a transformer-attention formula):

`ACTIVE SALIENCE ~ objective_intersection x state_delta_potential x currentness/contradiction/authority/consequence x source_resolvability`, subject to hard negative-space inhibition.

Before hydration, predict what owner/source/authority/currentness/negative-space structure should appear. Hydrate only enough to test. Contradiction marks the compact prior stale.

### Research-state shorthand

- **CLICKED** = demonstrates the relational grammar behaviorally; an aha/self-report is insufficient.
- **JACKED-IN** = has live access to the persistent source-addressable substrate and its current owners/sources/generations.

Test the 2 x 2 matrix: un-oriented/unconnected; oriented/unconnected; un-oriented/connected; oriented/connected.

### Cognitive-economy metrics

Track active-body ratio, active-decision-surface width, branch retention, cold-branch recovery, state-delta yield/source, source-descent precision, wrong-route rejection, false-prior correction, counterevidence recovery, re-entry operations and verified lifecycle cost.

### Spatial/perceptual L0

Human and AI manifestations may differ while sharing stable referents. Give the AI semantic identity/topology/state/authority/provenance first; request bounded pixels/depth only when uncertainty, contradiction, consequence or verification earns deeper perceptual resolution.

### Anti-confirmation / treatment discipline

A stable grammar should make exceptions and guarantee-boundary mismatches **more** salient, not easier to rationalize away. Treat filenames, relation labels, hot/cold annotations and topology as part of the experimental representation treatment. For a clean test, remove directional labels while preserving the underlying world and ask whether the worker still derives source necessity and lawful next state.
