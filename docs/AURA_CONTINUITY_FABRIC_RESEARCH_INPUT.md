# Aura Continuity Fabric — External Research Input

## Purpose

This bounded research input asks Aura's own architecture harness to determine where a coherent continual-learning and continuity layer belongs inside the existing system. It is research evidence only, never patch authority.

## Research clusters to integrate

1. **Intrinsic state sensitivity and safe-update geometry**
   - Quantum Elastic Weight Consolidation and quantum Fisher geometry.
   - Fisher-ellipsoid safe regions and alignment-preserving update budgets.
   - Dynamic importance masks rather than one global consolidation penalty.
   - Sparse, low-rank, Kronecker, and dominant-direction approximations instead of full all-pairs geometry.

2. **Protected computational pathways**
   - Preserve verified routes and role-labelled pathways rather than freezing every participating component.
   - Distinguish replaceable implementations from non-replaceable roles, authority boundaries, and verifiers.
   - Search for low-interference or unused architectural directions when adding new capability.

3. **Memory admission, evidence retention, and consolidation**
   - Preserve immutable raw episodes and exact evidence beside summaries or crystals.
   - Admit persistent memories using utility, grounding, novelty, recurrence, source diversity, Purpose compatibility, sensitivity, contradiction status, privacy, and replacement availability.
   - Delay deeper consolidation until recurrence or high consequence justifies it.
   - Support promotion and demotion across raw trace, episodic memory, procedural skill, and declarative rule.

4. **Replay and reproof**
   - Replay can create negative transfer; select Crucible scenarios by affected pathways, task compatibility, sensitivity coverage, contradictions, and regression history.
   - High sensitivity increases the burden of verification rather than permanently freezing a component.

5. **Adaptive compression and exact recall**
   - Allocate ST3GG fidelity according to behavioural and authority sensitivity.
   - Prefer deterministic omission, deduplication, symbolic encoding, exact pointers, and tool-output masking before LLM summarization.
   - Escalate from compact summaries to exact source when evidence sufficiency is not met.

6. **Active graph reconstruction**
   - Combine fast similarity or pointer retrieval with deliberate Relationship Atlas traversal.
   - Reconstruct Cue/Tag/Content or participant/evidence paths iteratively, pruning irrelevant or contradicted branches until sufficiency is met.

7. **Model and attention sensitivity**
   - Measure how prompt structure, context ordering, compression level, endpoint identity, provider drift, and routing choices affect verified task success.
   - Allocate attention and Council depth using uncertainty multiplied by consequence and Purpose relevance.

8. **Topology consequence mapping and visualization**
   - Weight topology signatures by consequence and protected pathways, not only counts and graph density.
   - Visualize grounded truth, load-bearing importance, instability, mutation range, dependency fracture lines, and authority requirements in the Observatory.

## Candidate unifying concept

**Purpose-Conditioned State Geometry (PCSG)** is a read-only measurement plane that publishes evidence-bound sensitivity receipts. It does not own truth, memory, routing, execution, policy, or patch authority.

A broader system name is **Aura Continuity Fabric**, composed from existing canonical owners:

- Purpose and human/community authority define preservation obligations.
- DIKWP defines epistemic meaning, provenance, and promotion stage.
- J-Space represents objective-scoped active state.
- Crucible performs bounded perturbation, replay, and reproof.
- PCSG measures component, pathway, Purpose, safety, compression-loss, and interaction sensitivity.
- Relationship Atlas records protected pathways, missing roles, candidate low-interference wiring, and prohibitions.
- QDKT stores admitted observations and verified crystals while retaining raw evidence references.
- ST3GG chooses compression fidelity and exact-recall escalation.
- FST/Planning Board/Model Cognome/Dynamic Attention adapt routes and resource depth.
- Observatory exposes the geometry for human understanding.

## Questions for Aura-native analysis

1. Which existing canonical owner should host each contract and computation?
2. What should remain a compiled view or advisory projection rather than a new subsystem?
3. Which existing motifs, schemas, receipts, deltas, or replay surfaces can be extended without duplication?
4. Which relationships are already wired, partially wired, overlapping but unwired, auxiliary, missing, or prohibited?
5. What is the smallest high-leverage implementation slice?
6. Which proposed integrations create circular authority, self-verification, cross-Arena coupling, or research-to-production hazards?
7. Where would the new layer reduce token use, regressions, negative transfer, stale memory, and overprotection?
8. Which initially attractive integrations should be deferred because Aura already has a superior native mechanism?

## Required invariants

- Exact source spans, hashes, tests, and canonical owners remain patch authority.
- Similarity, VSA projections, sensitivity values, memory crystals, ST3GG handles, and Atlas classifications remain advisory unless independently grounded.
- Planning proposes; verification proves; human or community authority decides.
- Raw evidence is retained or addressably recoverable whenever a compressed or consolidated form persists.
- No component may verify and promote its own result without independent corroboration.
- High sensitivity changes verification burden and mutation budget; it does not create automatic immutability.
- All scores are Purpose- and objective-conditioned, freshness-bound, and reprovable.
