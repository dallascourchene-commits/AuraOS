# Final Merge Gates

The final pull request may merge only when:

- exact-head workflow passes;
- focused and retained tests pass;
- architecture evidence compiles;
- documentation is synchronized;
- generated navigation is current;
- Codex findings are resolved;
- CodeRabbit findings are resolved;
- no unresolved review thread remains;
- merge uses the exact reviewed head SHA;
- the user's authorization remains in force.
