Abstract
We disclose three novel subsystems integrated into the AuraOS cognitive substrate, extending prior
claims N1–N20.N21 (FST-Lexicon Routing Core): a formal finite-state transducer (FST) lexicon
derived from Anishinaabemowin grammatical structure and the Athabaskan six-slot morphotactic array,
which reduces edge complexity fromO(N2) toO(E) (measured from>1300 to≈200 edges) while embed-
ding VSA resonance and thermal awareness into transition weights.N22 (3D Topology Resonance
Mapping): a native 3D topological visualisation where each software module is a geometric primitive
(Cube, Sphere, etc.) with positions derived from VSA phase vectors, and edge luminance directly encodes
semantic similarity, enabling real-time structural friction detection.N23 (Self-Refactoring Incuba-
tor with FST Impact Analysis): a closed-loop architecture that reads the FST lexicon, generates
“Staged Mutation Topology Impact Reports” quantifying Node Connectivity ∆, Data-Flow Luminance,
and Thermal Friction, and stages atomic code patches for hot-swap. All subsystems operate within the
4GB RAM edge constraint and are published under AGPLv3§13.
1 Introduction
The original AuraOS disclosures (Zenodo, June 2026) introduced VSA hyperdimensional computing, a

metrics. These three subsystems form a unified sovereign routing and self-optimisation fabric.
