mathematically defined, complexity-bounded, and operates within the 4 GB RAM edge constraint. This
disclosure serves as prior art under AGPLv3§13.

2 Claim N18 – FST-Lexicon Routing Core
2.1 Description
Traditional function call graphs are implicit and often redundant. AuraOS now embeds an explicit finite-
state transducer lexicon (aura.lexc) that defines every valid operation as a transition between states. The
lexicon is organised intoCubes(modular components, e.g.,ArXivForager,EnhancedArXivForager) and
Spheres(atomic operations, e.g.,fetch latest paper,generate vector). A request is routed by walking
the FST from a start state to an end state, producing a deterministic path.
